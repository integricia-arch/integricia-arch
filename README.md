## Cómo trabajamos

| Paso | Qué pasa |
|---|---|
| **1. Medir** | Medidor 3R: rotación de inventario, rendimiento por hora-persona y la restricción que te está deteniendo. |
| **2. Diagnosticar** | Método en seis pasos verificables, con control de etapa y avance medido. |
| **3. Construir** | Solo lo que el diagnóstico justifica. Un sistema que el equipo no usa cuesta más que no tenerlo. |

El método no es nuestro: es de la industria (Goldratt, Shewhart, Toyota, ISO 9001) y funciona hace ochenta años.
